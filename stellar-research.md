# Stellar/Soroban research notes

- Official wallet guidance: Stellar Wallets Kit supports Albedo, Freighter, Hana, Ledger, Trezor, Lobstr, Rabet, WalletConnect, xBull, HOT Wallet and others. Freighter is a non-custodial browser wallet. Source: https://developers.stellar.org/docs/tools/developer-tools/wallets
- Soroban JavaScript flow: use `@stellar/stellar-sdk`, `@stellar/stellar-sdk/contract`, and `@stellar/stellar-sdk/rpc`; construct or use `Client.from({ contractId, networkPassphrase, rpcUrl, publicKey, signTransaction })`; contract calls are simulated and submitted via `signAndSend`. Source: https://developers.stellar.org/docs/build/guides/transactions/invoke-contract-tx-sdk
- Soroban signing: transaction-envelope signing is for G-account source + fees; auth-entry signing supports G/C accounts and fee-payer flows. Recording simulation returns auth entries; enforcing simulation validates signatures and resource estimates. Auth entries include expiration ledger and nonce. Source: https://developers.stellar.org/docs/build/guides/transactions/signing-soroban-invocations
- SEP-50 NFT interface: token ID is an unsigned integer; standard functions include balance, owner_of, transfer, transfer_from, approve, approve_for_all, get_approved, is_approved_for_all, name, token_uri and metadata. Metadata JSON contains name, description, image, external_url and attributes. Source: https://github.com/stellar/stellar-protocol/blob/master/ecosystem/sep-0050.md
- Official indexer guidance: direct RPC is insufficient for paginated portfolios and historical ownership; use off-the-shelf portfolio/indexer APIs or a custom ETL/app database. Options mentioned include Alchemy Stellar Data API, OBSRVR, Mercury/Retroshades, Goldsky Mirror, SubQuery, Allium and others. Source: https://developers.stellar.org/docs/data/indexers
- Current StellaNova implementation: Vite/React/TypeScript frontend, Express API, PostgreSQL read models, Privy embedded Stellar wallets and Freighter support, Soroban NFT and marketplace contracts, Testnet payments, event indexer, admin operations and transaction reconciliation. The product owner confirms the core wallet, mint/indexing, social, marketplace and notification user journeys work in the running app. CI covers frontend/server TypeScript, frontend build, and contract unit tests; it does not yet replay complete Express/PostgreSQL journeys automatically.
